# Rolyang Project Roadmap

This document outlines the future development trajectory for both the Rolyang Admin Dashboard and its integration with the main Rolyang Music App.

## Phase 1: Dashboard Refinements (Current Phase)
- [x] Implement Secure Master Password Authentication
- [x] Build User Tier Toggling (Free vs Paid)
- [x] Build Featured Banners Manager (with Drag & Drop reordering)
- [x] Complete Upload Media system for Tracks and Albums
- [ ] Add bulk delete functionality for Tracks/Albums
- [ ] Implement Search across Tracks, Albums, and Artists globally

## Phase 2: Analytics & Reporting
- [ ] **Real-time Listening Stats:** Track how many times specific songs are played in the Rolyang app and display charts on the dashboard.
- [ ] **Revenue & Subscriptions:** Track the conversion rate of Free to Paid users over time.
- [ ] **User Demographics:** Display geographic and device data of active listeners.

## Phase 3: The "Contributor Portal" Spinoff
*The vision to expand management beyond just the solo Administrator.*
- [ ] Extract the Artist Profile manager into a standalone web application: **Rolyang for Artists**.
- [ ] Allow musicians to log in using their own credentials to view their specific track analytics.
- [ ] Allow artists to submit tracks for Admin approval via the dashboard instead of direct publishing.

## Phase 4: Rolyang App Integrations
- [ ] **Push Notifications:** Send FCM (Firebase Cloud Messaging) push notifications directly from the Admin Dashboard to Rolyang App users (e.g., "New Album just dropped!").
- [ ] **Dynamic Playlists:** Allow admins to create custom "Curated Playlists" (like "Top Hits of the Week") directly from the dashboard that sync to the mobile app's home screen.
- [ ] **Lyric Synchronization:** Add a Lyrics Editor to the Track management page to supply synced lyrics to the mobile audio player.
